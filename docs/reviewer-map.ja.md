# 実装・検証・今後の実証の対応表

[ホーム](../README.ja.md) · [English](reviewer-map.md) · [試用ガイド](demo-guide.ja.md)

製品の説明を、実際の動作と保存済みの証拠に結び付ける資料です。**実装**は保存済みソースでの確認、**検証記録**は版を特定した技術確認、**今後の実証**は効果をまだ主張できない事項として区別します。

## 3つの観点で確認する

1. **理解する**：[構成図と資料・判断の流れ](architecture.ja.md)で、誰が担当し、何を根拠とし、誰が終了を決めるかを確認します。
2. **試す**：[CL-001のガイド](demo-guide.ja.md)と[完了・訂正PDF](../demo-data/README.md)で、症例・原資料・履歴を確認します。引継ぎはCL-002で確認できます。
3. **評価する**：以下の動作を[版別の検証](validation.ja.md)、[運用上の制御](security-and-operations.ja.md)、[制約](scope-and-limitations.ja.md)と照合します。

## 機能と根拠

| 機能 | 実装・デモ | 確認できる根拠 | 境界 |
| --- | --- | --- | --- |
| 受診済みの中に残る未完了の発見 | 原文参照付きのルールで受診と検査実施を区別 | CL-001、v0.4.11の原文・経路試験 | 語句照合で臨床的な完備性は保証しない。 |
| 責任の明確化 | 引受けまで現担当を保持し、次の対応に担当・予定を記録 | CL-002、v0.4.11の業務・経路試験 | 引受けは模擬で、紹介先の認証はない。 |
| PDFの追跡 | 原本、抽出文・ハッシュ、比較確認、同じ症例への登録 | 公開PDF、v0.4.11のPDF/API通し確認 | テキストPDFが対象。OCR・発行者確認はない。 |
| 後日の事実と訂正の区別 | 新規追加と明示的な置換を区別し、旧資料を保持 | CL-001、API・ブラウザの訂正確認 | 架空シナリオで、臨床効果の研究ではない。 |
| 現在の根拠に基づく人の判断 | 資料に結び付く判断、必要確認、対応完了、現在の確認結果で終了を制御 | v0.4.11の業務・AI制御・完了条件試験 | デモ役割であり、本人認証付きの診療承認ではない。 |
| 患者の希望への対応 | 案内への回答、追加説明希望、支援希望、保留 | v0.4.11の患者回答・経路試験 | 理解度や実患者の利用評価は未測定。 |
| 別の終了区分 | 辞退・代替方針を根拠付きで記録し、元の検査を実施済みにしない | v0.4.11の経路試験 | 施設の臨床方針は別途承認が必要。 |
| 更新時の整合性 | 競合検出、作業領域分離、履歴保持、利用上限 | v0.4.11のSQL・Firestoreエミュレータ・分離試験 | 本番負荷・サービス水準は未検証。 |
| 英・日・アラビア語 | 同じ記録、アラビア語RTL、言語ごとの予定日時 | 現行EN/JAの到達性、日本時間の表示、過去の言語確認 | 専門的な言語監修は未実施。原本は自動翻訳しない。 |

## 実施設での試行仮説と測定

想定利用者は、健診後の異常所見を複数の担当間でフォローする調整担当者と医療者です。初期の導入主体としては、フォローの完了に責任を持つ医療機関・健診事業を想定します。資料と対応を結び付け、責任を明確にすることで、追跡されない未対応と資料変更時の確認負担を減らせるかを検証します。検証済みの販売条件ではありません。

| 今後の問い | 測定案 | 必要な条件 |
| --- | --- | --- |
| 適切なフォローが増えるか | 対象経路のうち、適切な終了区分と根拠が記録された割合 | 施設が定めた対象・終了基準、比較期間。 |
| 対応が早まるか | 要対応結果から担当引受け・次の適切な行動までの時間 | 比較可能な時刻と症例構成の確認。 |
| 資料確認が改善するか | 判定済みケースでの未解消不一致・不適切な終了 | 独立した専門家評価、固定ケース、誤りの検討。 |
| 調整の負担が減るか | 症例確認・引継ぎに要する担当者の時間 | 実作業の観測、分母、比較方法。 |
| 次の行動が伝わるか | 課題に沿った理解、追加説明の必要、使いやすさ | 同意を得た利用者評価、言語・支援ニーズの反映。 |

試行前には、経路、本人確認、データの取扱い・保持、配置・モデル処理、必要な接続、エスカレーション責任、評価方法を合意します。価格、調達条件、支払意思、提供原価は実施設で確認する事項です。実証時期や提携先の確約は含みません。
